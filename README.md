# Minidrive

Stripped-down clone of Google Drive. 

The DB schema, including directory structuring and design, were made by me (with some help from online sources).

This was made for a fullstack bootcamp as a project to learn ORMs, and solidify DB, Express, and SSR knowledge.

Note: UI is barebones at the moment, as my main focus was on the backend.

## Tech stack

- Javascript (no Typescript sadly)
- Express.js
- Prisma ORM
- PostgresQL
- Supabase Storage, for storage
- Multer, for upload handling
- Passport.js, for auth
- EJS, for the frontend
